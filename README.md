## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the home page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

The project board at `/portfolio` links to five project detail pages. Edit their stories, technology lists, and demo assets in `src/app/portfolio/projects.ts`; edit resume content in `src/app/resume/page.tsx`.

Product demos include pause/play controls and respect reduced-motion preferences. See the [Brain Cache demo guide](media/brain-cache-demo/README.md) and [Goof Balls demo guide](media/goof-balls-demo/README.md) for editing and rendering their source compositions.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to load Bricolage Grotesque, Libre Franklin, and Geist Mono.
